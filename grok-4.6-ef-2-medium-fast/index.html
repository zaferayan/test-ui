TEMEL ÖZELLİKLER

  • </>

    JSX

    JavaScript içine HTML benzeri sözdizimi yazarak daha okunabilir kodlar yazmanızı sağlar.

  • BİLEŞENLER (COMPONENTS)

    UI'ı bağımsız ve yeniden kullanılabilir parçalara böler, geliştirmeyi kolaylaştırır.

  • { }

    STATE & PROPS

    State (durum) değişen verileri, Props ise bileşenler arası veri iletişimini yönetir.

  • LIFECYCLE (YAŞAM DÖNGÜSÜ)

    Bileşenlerin oluşturulma, güncellenme ve kaldırılma aşamalarını yönetmenizi sağlar.

  • SANAL DOM

    Gerçek DOM'u en verimli şekilde güncelleyerek daha iyi performans sunar.
