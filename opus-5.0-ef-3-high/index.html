Kullanıcı Arayüzleri İçin
JavaScript Kütüphanesi

React, etkileşimli ve yüksek performanslı web uygulamaları geliştirmek için kullanılan, deklaratif ve bileşen tabanlı bir JavaScript kütüphanesidir.

Bileşen Tabanlı

UI'ları küçük, yeniden kullanılabilir bileşenler halinde oluşturur.

Yüksek Performans

Sanal DOM ile yalnızca değişen bölümleri güncelleyerek daha hızlı ve verimli çalışır.

Tek Yönlü Veri Akışı

Veri akışı daha öngörülebilir ve hataları tespit etmek daha kolaydır.

Geniş Ekosistem

Zengin araçlar, topluluk desteği ve güçlü bir ekosisteme sahiptir.

Temel Özellikler

JSX

JavaScript içine HTML benzeri sözdizimi yazarak daha okunabilir kodlar yazmanızı sağlar.

Bileşenler (Components)

UI'ı bağımsız ve yeniden kullanılabilir parçalara böler, geliştirmeyi kolaylaştırır.

State & Props

State (durum) değişen verileri, Props ise bileşenler arası veri iletişimini yönetir.

Lifecycle (Yaşam Döngüsü)

Bileşenlerin oluşturulma, güncellenme ve kaldırılma aşamalarını yönetmenizi sağlar.

Sanal DOM

Gerçek DOM'u en verimli şekilde güncelleyerek daha iyi performans sunar.

Basit Bir React Bileşeni

import React from 'react';

function MerhabaDunya() {
  return (
    <div style={{ color: '#61dafb',
                  fontSize: '20px' }}>
      Merhaba Dünya! 👋
    </div>
  );
}

export default MerhabaDunya;
Merhaba Dünya! 👋
